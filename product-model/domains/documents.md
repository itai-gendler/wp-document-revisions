# Documents

Working on documents in the Documents menu, from the All Documents list and the edit screen it opens: checking out, revising, restoring, describing, publishing, assigning workflow states and owners, trashing and deleting.

## Boundary

It does not own the list of workflow states itself, which is kept under Workflow States, nor checking and repairing document structures, which belongs to Validate Structure, nor reading documents on the site's own pages.
